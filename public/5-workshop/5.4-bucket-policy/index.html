5.4 Thắt chặt Bảo mật với S3 Bucket Policy

Bài Lab 4: Cấu hình Chính sách S3 Bucket Policy Kiểm soát Truy cập Nâng cao

1. Mục tiêu bài thực hành

  • Sử dụng S3 Bucket Policy viết bằng định dạng JSON để phân quyền chi tiết.
  • Thiết lập cơ chế bảo mật nghiêm ngặt: Chỉ cho phép các yêu cầu (requests) xuất phát từ đúng mã VPC Endpoint nội bộ được quyền thao tác dữ liệu. Toàn bộ các truy cập từ Internet công cộng hoặc tài khoản ngoài sẽ bị chặn đứng (Deny).

2. Các bước triển khai chi tiết

Bước 4.1: Lấy thông tin ID của VPC Endpoint

  1. Vào dịch vụ VPC -> Chọn mục Endpoints.
  2. Tìm đến cái Thien-S3-Endpoint đã tạo ở bài Lab 3.
  3. Sao chép lại mã VPC Endpoint ID (Mã này thường có dạng là vpce-xxxxxxxxxxxxxxxxx).

Bước 4.2: Cấu hình Bucket Policy trên S3

  1. Chuyển sang dịch vụ S3 -> Click chọn vào tên Bucket của bạn (thien-aws-workshop-bucket-2026).
  2. Chọn tab Permissions (Quyền truy cập) -> Kéo xuống mục Bucket policy và nhấn Edit.
  3. Copy đoạn mã JSON dưới đây và dán vào trình biên tập (Nhớ thay thế các thông tin trong ngoặc nhọn <> bằng thông tin thực tế của bạn):
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "Allow-Access-From-Specific-VPCE-Only",
            "Effect": "Deny",
            "Principal": "*",
            "Action": "s3:*",
            "Resource": [
                "arn:aws:s3:::<TÊN-BUCKET-CỦA-BẠN>",
                "arn:aws:s3:::<TÊN-BUCKET-CỦA-BẠN>/*"
            ],
            "Condition": {
                "StringNotEquals": {
                    "aws:sourceVpce": "<ID-VPC-ENDPOINT-CỦA-BẠN>"
                }
            }
        }
    ]
}
