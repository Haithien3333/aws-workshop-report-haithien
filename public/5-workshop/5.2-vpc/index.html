5.2 Thiết kế Hạ tầng Mạng với Amazon VPC

Bài Lab 2: Khởi tạo và Định tuyến Hệ thống Mạng Amazon VPC

1. Mục tiêu bài thực hành

  • Khởi tạo một mạng ảo độc lập Amazon VPC an toàn trên Cloud.
  • Phân chia dải mạng thành Public Subnet (vùng công cộng) và Private Subnet (vùng kín bảo mật).
  • Cấu hình Internet Gateway (IGW) và Route Table để cấp quyền truy cập Internet hợp lý.

2. Các bước triển khai chi tiết

Bước 2.1: Tạo Mạng ảo VPC

  1. Trên thanh tìm kiếm AWS Console, chọn dịch vụ VPC.
  2. Nhấn Create VPC -> Chọn mục VPC only.
  3. Đặt tên: Thien-VPC.
  4. Điền dải địa chỉ IP (IPv4 CIDR block): 10.0.0.0/16. Nhấn Create.

Bước 2.2: Phân chia các dải mạng con (Subnets)

Tiến hành tạo 2 vùng mạng con trong VPC vừa tạo:

  1. Public Subnet:
    • Tên: Thien-Public-Subnet
    • Dải IP (CIDR): 10.0.1.0/24
  2. Private Subnet:
    • Tên: Thien-Private-Subnet
    • Dải IP (CIDR): 10.0.2.0/24

Bước 2.3: Cấu hình cổng Internet Gateway và Định tuyến

  1. Vào mục Internet Gateways -> Nhấn Create internet gateway -> Đặt tên Thien-IGW.
  2. Chọn IGW vừa tạo -> Nhấn Actions -> Chọn Attach to VPC -> Chọn Thien-VPC.
  3. Vào mục Route Tables, chọn bảng định tuyến của Public Subnet, thêm một dòng Route:
    • Destination: 0.0.0.0/0 (Toàn bộ Internet)
    • Target: Chọn Internet Gateway -> Chọn Thien-IGW.

3. Kết quả đạt được & Ảnh minh chứng

Hạ tầng mạng đã được thiết lập đúng cấu trúc phân tách giữa vùng mạng ngoài và vùng nội bộ.
