5.3 Lưu trữ S3 và Cấu hình VPC Endpoint

Bài Lab 3: Triển khai Amazon S3 và Kết nối Riêng tư bằng VPC Gateway Endpoint

1. Mục tiêu bài thực hành

  • Khởi tạo hệ thống lưu trữ đối tượng an toàn với Amazon S3.
  • Cấu hình VPC Gateway Endpoint để cho phép các máy ảo trong vùng mạng kín (Private Subnet) có thể truy cập trực tiếp dữ liệu trên S3 mà không cần đi qua môi trường Internet công cộng, giúp tối ưu bảo mật và tăng tốc độ truyền tải.

2. Các bước triển khai chi tiết

Bước 3.1: Khởi tạo Amazon S3 Bucket

  1. Truy cập dịch vụ S3 trên AWS Console -> Nhấn Create bucket.
  2. Đặt tên Bucket (phải viết liền, không dấu, duy nhất toàn cầu): thien-aws-workshop-bucket-2026.
  3. Giữ nguyên cấu hình Block Public Access (Chặn hoàn toàn truy cập nặc danh ngoài Internet) để đảm bảo an toàn. Nhấn Create bucket.

Bước 3.2: Khởi tạo VPC Endpoint (Gateway) cho S3

  1. Quay lại dịch vụ VPC -> Tìm đến mục Endpoints ở menu bên trái.
  2. Nhấn Create endpoint và điền thông tin:
    • Name: Thien-S3-Endpoint
    • Service category: Chọn AWS services.
    • Services: Tìm kiếm chữ s3 và chọn tệp có Type là Gateway (Ví dụ: com.amazonaws.ap-southeast-1.s3).
    • VPC: Chọn mạng Thien-VPC của bạn.
    • Route Tables: Tích chọn bảng định tuyến của Private Subnet để Hugo/AWS tự động gắn tuyến đường đi qua Endpoint này.
  3. Nhấn Create endpoint.

3. Kết quả đạt được & Ảnh minh chứng

Sau khi cấu hình xong Endpoint, trong bảng Route Table của Private Subnet sẽ tự động xuất hiện một dòng định tuyến có Target dạng vpce-xxxxxx hướng thẳng tới S3.
